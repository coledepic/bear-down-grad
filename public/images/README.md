# Photos go here

Drop in real photos with these exact filenames and the site will pick them up automatically
(no code changes needed). Until a file exists, that spot just shows a navy/red gradient —
it won't break or show a broken-image icon.

| Filename | Used for | Suggested size |
|---|---|---|
| `hero-both.jpg` | Big background photo on the combined (`/`) page | 1920×1080 or larger, landscape |
| `hero-kylie.jpg` | Big background photo on Kylie's page (`/kylie/`) | 1920×1080 or larger, landscape |
| `hero-austin.jpg` | Big background photo on Austin's page (`/austin/`) | 1920×1080 or larger, landscape |
| `grad-kylie.jpg` | Kylie's card in the "Meet the graduates" section | 800×800 or larger, portrait/square works best |
| `grad-austin.jpg` | Austin's card in the "Meet the graduates" section | 800×800 or larger, portrait/square works best |

The hero photos sit behind a dark navy overlay (for text readability), so a slightly busy or
bright photo still reads fine — it doesn't need to be a plain studio shot.
